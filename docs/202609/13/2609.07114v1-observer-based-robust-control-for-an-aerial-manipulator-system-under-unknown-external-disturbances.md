## 摘要
本文研究了由作为无人飞行器的四旋翼和作为操作器的机械臂组成的空中机械臂系统的数学建模与控制。通过将整体质心速度和系统姿态作为约束条件，建立了动力学模型，得到了简化的两个解耦子系统：锁定（整体平移）子系统和形状空间（驱动或整体旋转）子系统，二者均受到外部扰动影响。由于系统存在机械耦合，一个关键挑战是：第一个子系统中的常值有界扰动会在第二个子系统中表现为时变且状态相关的扰动。考虑到四旋翼本身是不稳定的，如果这些扰动和耦合效应不能得到有效处理，机械臂（RM）在飞行过程中的运动可能进一步危及整个QRM系统的稳定性。为解决这一问题，我们提出了一种基于连续非线性扰动观测器的反馈控制律，该控制律能够独立控制各子系统，同时系统地消除交叉耦合效应。通过模拟实际工况的多次仿真验证了所提控制器的有效性，从而证明了其实际应用价值，并突出了本文的核心贡献。

## Abstract
This paper addresses the mathematical modeling and control of an aerial manipulator system comprising a quadrotor as the uncrewed aerial vehicle and a robotic arm as the manipulator. The dynamic model is established by identifying the overall center-of-mass velocity and the system's orientation as constraints, yielding a simplified, two-decoupled subsystems: a locked (overall translation) subsystem and a shape-space (actuation or overall rotation) subsystem, both subjected to external disturbances. Since the system is mechanically coupled, a critical challenge arises where constant bounded disturbances in the first subsystem manifest as time-varying, state-dependent disturbances in the second subsystem. Given that the quadrotor is inherently unstable, the movement of the robotic manipulator (RM) during flight can further jeopardize the stability of the entire QRM system if these disturbances and coupling effects are not effectively managed. To address this, we present a continuous nonlinear disturbance observer-based feedback control law, which enables the independent control of each subsystem while systematically eliminating cross-coupling effects. The efficacy of the proposed controller is validated through multiple simulations emulating practical operating conditions, thereby substantiating its real-world applicability and highlighting the core contributions of this work.

## 2. 方法论

### 2.1 建模思路（几何/能量分解）

- **构型空间**：系统含四旋翼（6 DoF）与 2 自由度机械臂（关节角 θ₁、θ₂），构型流形为
  **M = R³ ⋊ SO(3) × S²**，广义坐标 **q = [η₀ᵀ, Φᵀ, Θᵀ]ᵀ**，其中 η₀ 为四旋翼质心位置、Φ 为 ZYX 欧拉角（滚转/俯仰/偏航）、Θ 为关节角。

- **拉格朗日动力学**：先建立完整耦合动力学
  **M(q)q̈ + C(q,q̇)q̇ + G(q) = τ + τd**（8 维），其中质量矩阵 M 由四旋翼与机械臂的动能、惯量张量 I₀/I₁、雅可比 Jv₁/Jω₁ 组合而成，C 通过 Christoffel 符号保证 **Ṁ − 2C 反对称**。

- **被动分解（Passive Decomposition）**：
  - 将构型拆为"锁定变量" **η₀** 与"形状变量" **ζ = [Φ, Θ]ᵀ**；
  - 定义选择映射 f(q)=ζ 及水平/切向分布 **Dq = ker(Df)**（锁定方向，即 ζ̇=0 的纯平动）；
  - 用动能诱导的黎曼度量 **⟨⟨u,v⟩⟩q = uᵀM(q)v** 定义正交补 **Dq⊥**，得到直和分解 **TqM = Dq ⊕ Dq⊥**；
  - 定义耦合矩阵 **N(ζ) = −(1/mqm)·M̃₁₂(ζ)**，并构造变换矩阵 **B(ζ) = [[I₃, N(ζ)],[0, I₅]]**，使 q̇ = B(ζ)ν。

- **解耦结果**：得到两个二阶子系统：
  - **锁定子系统**：**mqm·η̈qm + GL = τL + τdL**（总质心平动，含重力项 GL，无 Coriolis 项）；
  - **形状子系统**：**MS(ζ)ζ̈ + CS(ζ,ζ̇)ζ̇ = τS + NᵀτdL**（内部姿态与关节动力学，**无重力项**，但受经 Nᵀ 投影的耦合扰动）。
  - 证明 **Ṁ̄ − 2C̄ 仍为反对称**（Lemma 1），且 C̄ 为分块形式 [[0,0],[0,CS]]，即**平动与内部构型间无 Coriolis 耦合**。

- **扰动传播刻画**：假设仅四旋翼平动受常值有界扰动 τdL（Assumption 1：τ̇dL=0，‖τdL‖≤σ），令 τdS=0，则形状子系统的等效扰动为 **NᵀτdL**——正是"常值扰动转化为时变状态相关扰动"的数学体现。

### 2.2 控制律设计（NDOBC）

- **滤波误差变量**：定义跟踪误差 ex1, ex2, ey1, ey2，及滤波变量
  **Sl = ex2 + λl·ex1**，**Ss = ey2 + λs·ey1**（λl、λs 为正定对角阵）。

- **非线性扰动观测器（NDO）**：引入辅助状态 z，估计
  **τ̂dL = z + γl·mqm·Sl**，其动态为
  **ż = −γl(τL − GL − mqm·ẍ1d + τ̂dL + mqm·λl·ėx1)**。
  由此得估计误差动态 **τ̃̇dL = −γl·τ̃dL**（指数收敛）。**采用观测器而非自适应律，是为了避免由推力反解期望姿态造成的代数环问题**。

- **控制律**：
  - 锁定控制（虚拟控制力）：**uct = GL − τ̂dL + mqm·ẍ1d − mqm·λl·ėx1 − Kl·Sl**，并证明 **τL = uct**（Corollary 1，在姿态收敛到 Rd₀e₃ = uct/‖uct‖ 的前提下）。
  - 形状控制：**τS = CS(y1,y2)(−λs·ey1 + ẏ1d) − N(ζ)ᵀτ̂dL + MS·ÿ1d − MS·λs·ėy1 − Ks·Ss**。

- **欠驱动处理**：由虚拟控制力 uct 反解期望滚转/俯仰角（式 38–39），期望偏航角由用户指定，实现推力矢量指向期望方向。

- **稳定性分析**：构造复合 Lyapunov 函数
  **V = ½(SlᵀmqmSl + τ̃dLᵀτ̃dL) + ½SsᵀMSSs**，
  利用 Young 不等式与 Rayleigh-Ritz 不等式，选取增益 Kl = (1/2ε₁)I₃ + K̄l、γl = ε₁/2 + γ̄l、Ks = (ε₂/2)I₅ + K̄s、γ̄l = ‖N‖² + 2ε₂γ，得
  **V̇ ≤ −ΓV**，证明 Sl、Ss、τ̃dL **指数收敛到零**，进而 ex1、ex2、ey1、ey2 → 0，且 τ̂dL → τdL、Nᵀτ̂dL → NᵀτdL。

- **辅助理论结果**：证明耦合矩阵范数有界（Claim 1）：**0 ≤ ‖N‖² ≤ 5m₁²l²/(4mqm²)**；附录给出旋转矩阵、M̄、Ḡ、CS 反对称性、Corollary 1 的完整推导。

### 2.3 轨迹生成（用于抓取-放置）

## 6. 主要结论与发现

1. 通过能量/被动分解，QRM 系统可被严格解耦为**锁定（质心平动）子系统**与**形状（姿态+关节）子系统**，且平动动力学不受机械臂运动产生的非线性惯性耦合力影响，形状动力学中**重力项被完全消除**。
2. 作用在四旋翼平动上的常值外部扰动，会通过状态相关映射 **N(ζ)** 传播为形状子系统中的**时变扰动**；论文给出了该传播机制的严格刻画。
3. 所提出的**连续非线性扰动观测器反馈控制律（NDOBC）** 能同时实现：锁定与形状变量的**指数收敛**、扰动估计 τ̂dL 与 Nᵀτ̂dL 对真实扰动的**指数逼近**，且控制信号**连续无抖振**。
4. 仿真表明：末端执行器可在约 4–6 s 内完成点镇定；五次多项式最小急动轨迹可支撑平滑的抓取-放置作业，姿态、关节、控制输入均平滑有界，验证了框架的实际可行性。
