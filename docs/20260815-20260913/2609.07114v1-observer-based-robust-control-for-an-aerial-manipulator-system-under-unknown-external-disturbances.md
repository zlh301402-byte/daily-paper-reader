## 摘要
本文研究一种由四旋翼无人机和机械臂组成的空中机械臂系统的数学建模与控制。通过将整体质心速度和系统姿态作为约束，建立动力学模型，得到简化的两个解耦子系统：锁定（整体平移）子系统和形状空间（驱动或整体旋转）子系统，二者均受到外部扰动影响。由于系统存在机械耦合，一个关键挑战在于：第一个子系统中的常值有界扰动会在第二个子系统中表现为时变且依赖于状态的扰动。鉴于四旋翼本身不稳定，若不能有效处理这些扰动和耦合效应，机械臂（RM）在飞行过程中的运动可能进一步危及整个 QRM 系统的稳定性。为此，我们提出一种基于连续非线性扰动观测器的反馈控制律，能够在系统性地消除交叉耦合效应的同时，实现对各子系统的独立控制。通过模拟实际运行工况的多次仿真验证了所提控制器的有效性，从而证实了其实际适用性，并突出了本工作的核心贡献。

## Abstract
This paper addresses the mathematical modeling and control of an aerial manipulator system comprising a quadrotor as the uncrewed aerial vehicle and a robotic arm as the manipulator. The dynamic model is established by identifying the overall center-of-mass velocity and the system's orientation as constraints, yielding a simplified, two-decoupled subsystems: a locked (overall translation) subsystem and a shape-space (actuation or overall rotation) subsystem, both subjected to external disturbances. Since the system is mechanically coupled, a critical challenge arises where constant bounded disturbances in the first subsystem manifest as time-varying, state-dependent disturbances in the second subsystem. Given that the quadrotor is inherently unstable, the movement of the robotic manipulator (RM) during flight can further jeopardize the stability of the entire QRM system if these disturbances and coupling effects are not effectively managed. To address this, we present a continuous nonlinear disturbance observer-based feedback control law, which enables the independent control of each subsystem while systematically eliminating cross-coupling effects. The efficacy of the proposed controller is validated through multiple simulations emulating practical operating conditions, thereby substantiating its real-world applicability and highlighting the core contributions of this work.

## 2. 方法论

### 2.1 建模思路

- **构型空间**：M = R³ ⋊ SO(3) × S²，广义坐标 q = [η₀ᵀ Φᵀ Θᵀ]ᵀ ∈ R⁸，其中 η₀ 为四旋翼质心位置，Φ = [φr φp φy] 为 ZYX 欧拉角，Θ = [θ1 θ2] 为机械臂两转动关节角（一绕 z 轴、一绕 y 轴）。
- **动力学**：由动能（四旋翼 + 机械臂平动/转动能）与重力势能建立标准 Euler–Lagrange 方程
  **M(q)q̈ + C(q,q̇)q̇ + G(q) = τ + τd**
  其中 M(q) 为 8×8 质量矩阵，C 由 Christoffel 符号定义（保证 Ṁ − 2C 反对称）。
- **扰动假设（Assumption 1）**：作用在平移方向的扰动 τdL 为常值且有界 ‖τdL‖ ≤ σ；内部形状扰动假设为零（τdS = 0），因为内部扰动主要由任务空间扰动经 N(ζ) 投影产生。

### 2.2 被动分解（核心思想）

- 将 q 分为**锁定变量** η₀ 与**形状变量** ζ = [Φᵀ Θᵀ]ᵀ；定义选择映射 f(q) = ζ = Hq。
- 利用惯性矩阵 M(q) 诱导的 Riemannian 度量 ⟨⟨u,v⟩⟩_q = uᵀM(q)v，构造正交直和分解
  **T_q M = D_q ⊕ D_q^⊥**（锁定分布 ⊕ 形状分布）
- 定义耦合矩阵 **N(ζ) := −(1/m_qm) M̃₁₂(ζ)**，得到坐标变换 q̇ = B(ζ)ν，B = [[I₃, N],[0, I₅]]。
- **解耦结果**（两个二阶子系统）：
  - 锁定系统：**m_qm η̈_qm + G_L = τ_L + τ_dL**（纯质心平动，无科氏项）
  - 形状系统：**M_S(ζ)ζ̈ + C_S(ζ,ζ̇)ζ̇ = τ_S + Nᵀτ_dL**（无重力项，但含扰动投影）
- **扰动传播机制**：τ_dL 为常值，但 N(ζ)ᵀτ_dL 随构型时变，故形状子系统承受**时变状态相关扰动**；同时该扰动会间接影响末端执行器精度。
- **理论支撑**：Lemma 1 证明 Ṁ̄ − 2C̄ 仍反对称；附录 D 证明 Ṁ_S − 2C_S 反对称；附录 F（Claim 1）给出 **‖N‖² ≤ 5m₁²l²/(4m_qm²)** 的界。

### 2.3 控制设计（NDOBC）

- **误差与滤波变量**：e_x1 = x1 − x1d，e_y1 = y1 − y1d；S_l = e_x2 + λ_l e_x1，S_s = e_y2 + λ_s e_y1。
- **非线性扰动观测器（避免自适应控制中推力↔期望姿态的代数环）**：
  - 估计量 τ̂_dL = z + γ_l m_qm S_l
  - 辅助状态更新 ż = −γ_l(τ_L − G_L − m_qm ẍ_1d + τ̂_dL + m_qm λ_l ė_x1)
  - 估计误差满足 **τ̃̇_dL = −γ_l τ̃_dL**，即指数收敛。
- **锁定控制律**：τ_L = u_ct = G_L − τ̂_dL + m_qm ẍ_1d − m_qm λ_l ė_x1 − K_l S_l。
- **形状控制律**：τ_S = C_S(−λ_s e_y1 + ẏ_1d) − N(ζ)ᵀτ̂_dL + M_S ÿ_1d − M_S λ_s ė_y1 − K_s S_s。

## 6. 主要结论与发现

- 通过被动分解可将 QRM 系统严格解耦为**锁定（质心平动）子系统**与**形状（姿态 + 关节）子系统**，其中：
  - 锁定子系统无科氏耦合项，形状子系统无重力项，二者在能量意义下正交；
  - 机械臂的内部运动**不会**作为内部扰动破坏四旋翼的质心平动跟踪。
- 作用在平移通道的**常值扰动会经状态依赖矩阵 N(ζ)ᵀ 传播为形状子系统的时变扰动**，这是耦合系统的本质特征，必须显式补偿。
- 提出的**连续非线性扰动观测器反馈控制律（NDOBC）** 能使锁定与形状子系统的跟踪误差、以及扰动估计误差**指数收敛到零**，且控制信号连续、无抖振（克服了滑模控制的不连续缺陷）。
- 仿真表明：
  - 点镇定任务中，姿态在约 4 s 内收敛，关节角在约 6 s 内收敛并保持稳定；
  - 抓放任务中，五次多项式（最小 jerk）轨迹使控制输入平滑、无饱和，末端执行器与质心轨迹均能精确跟踪参考；
  - 控制输入不收敛到零是合理的，因为需要持续抵消常值扰动，与扰动估计曲线一致；
  - 即使机械臂第一关节绕 z 轴转动，也不会引起四旋翼晃动/振荡，验证了解耦有效性。
- 结论性表述：该框架为复杂抓放环境中的空中操作提供了"鲁棒且可扩展"的基础，为后续实物实验铺路。

## 7. 优点

- **建模的几何严谨性**：基于 SE(3) × S² 流形、Riemannian 度量与正交分布分解建立模型，物理意义清晰（能量解耦而非数值近似解耦），并有 Lemma 1、附录 B/C/D/F 的完整推导支撑。
- **抓住了

**抓住了耦合扰动的本质机制**：明确区分"平移通道的常值有界扰动"与"经 N(ζ)ᵀ 映射后形状通道的时变状态相关扰动"，并针对性地在形状控制律中引入 −N(ζ)ᵀτ̂_dL 补偿项，理论上解释了为何常值扰动估计器仍能满足形状子系统的时变扰动抑制需求。
- **控制律的连续性**：与滑模/终端滑模等有限时间方法不同，NDOBC 全程使用连续控制信号，避免了抖振与不期望的 jerk，对飞行平台的执行机构（电机转速、舵机）更友好，也更符合机械臂关节伺服的物理约束。
- **扰动观测器设计的巧思**：采用"观测器 + 反馈项"而非纯自适应律，显式规避了自适应控制中推力指令与期望姿态之间的代数环问题；观测误差动态 τ̃̇_dL = −γ_l τ̃_dL 具有简洁的指数收敛形式，便于增益整定。
- **稳定性证明的完整闭环**：从 Ṁ − 2C 反对称性（Lemma 1、附录 D）到 ‖N‖² 的显式上界（附录 F, Claim 1），再到复合 Lyapunov 函数 V̇ ≤ −ΓV 的指数收敛结论，并给出 K_l、K_s、γ_l 的解析选取规则（含 ε₁、ε₂、γ̄_l 的自由度），理论链条自洽、可验证。
- **轨迹层的工程配套**：最小 jerk 五次多项式生成 + Algorithm 1 的末端—质心几何分配，使控制器不仅能镇定，还能执行连续抓放任务，具备一定的任务闭环完整性。
- **物理直觉清晰**：仿真中"机械臂第一关节绕 z 轴转动不引起四旋翼晃动"这一现象，直观印证了被动分解所宣称的能量正交性，对读者理解解耦机理有帮助。

## 8. 缺点与局限（客观审视）

- **实验证据薄弱**：如前所述，仅有 2 组纯数值仿真，无对比基线、无消融、无量化指标、无实物验证；"鲁棒""可扩展"等结论主要建立在数学证明而非实验对照之上，说服力受限。
- **扰动模型过于理想化**：Assumption 1 假设平移扰动为**常值且有界**，但真实风场（阵风、湍流）、地面效应、气动干扰、负载变化引起的是时变甚至高频扰动；文中也未讨论扰动上界 σ 的选取与控制器增益的关系（虽观测器不显式依赖 σ，但稳定性推导中的不等式放缩隐含了有界性前提）。
- **内部形状扰动被设为零**：τ_dS = 0 的假设回避了关节摩擦、连杆柔性、舵机死区、电机动力学等实际扰动源，削弱了模型的真实性。
- **模型阶数与计算负担的权衡未被充分讨论**：虽然声称相比全耦合 n 自由度模型降低了计算量，但 N(ζ)、M_S(ζ)、C_S 等仍需在线计算并求逆，文中未给出计算量对比或实时性分析（控制频率、单步耗时）。
- **期望姿态反解的条件性**：Corollary 1 的 τ_L = u_ct 依赖 R₀ → R₀ᵈ 的成立，而在大初始姿态误差（如仿真中 Φ(0) = [π/10, π/11, 0]）下的暂态耦合影响、以及 φ_dr、φ_dp 反解可能出现的奇异（推力方向与期望姿态冲突）未做充分讨论。
- **增益整定的主观性**：K̄_l、K̄_s、γ_l、λ_l、λ_s 等参数由人工给定，未给出系统化的整定流程或鲁棒裕度（如相位裕度、增益裕度）分析。
- **可复现性不足**：无仿真软件、求解器、步长、积分方法等细节，第三方难以精确复现曲线。

## 9. 改进建议与后续工作方向

- **补充对比实验**：在同一场景下与 PID、级联 PID、反步法、滑模/超螺旋滑模、无观测器的被动分解控制进行定量对比（RMSE、ISE、稳态误差、收敛时间、控制能量、最大 jerk）。
- **开展消融研究**：分别去除扰动观测器、去除 N(ζ)ᵀτ̂_dL 补偿项、改变 λ、K、γ 的量级，验证各模块的必要性与增益敏感性。
- **扩展扰动情形**：加入时变扰动、正弦/随机风、脉冲扰动、参数摄动（质量、惯量、连杆长度偏差）、测量噪声与延迟，检验鲁棒边界。
- **推进实物验证**：在真实四旋翼 + 机械臂平台上验证，关注执行器饱和、通信延迟、姿态估计误差等实际因素。
- **理论深化**：将扰动假设放宽为有界时变（‖τ̇_dL‖ ≤ σ_d），分析观测器在时变扰动下的一致有界性/渐近收敛条件；讨论闭环系统的输入-状态稳定性（ISS）与鲁棒裕度。
- **计算优化**：给出解耦模型的在线计算复杂度分析，探讨能否进一步简化 N(ζ)、M_S 的结构或采用递归/符号预计算以提升实时性。

## 10. 总体评价

本文在**理论建模与控制设计层面具有较高价值**：它把被动分解从"无扰动"推广到"平移通道受常值扰动"的情形，并敏锐地指出扰动经耦合映射 N(ζ)ᵀ 转化为形状通道时变扰动的机制，配合连续型非线性扰动观测器与完整的 Lyapunov 指数收敛证明，构成了一条清晰、自洽的方法论主线。其核心贡献在于**解耦的几何严谨性**与**控制律的无抖振特性**，对空中机械臂鲁棒控制研究具有参考意义。

但从**实证角度**看，本文仍停留在"仿真验证 + 理论证明"阶段：缺乏对比、消融、量化与实物实验，扰动假设偏理想，算力与仿真细节缺失，因而其"鲁棒性优越"的工程结论尚待更充分的证据支撑。总体而言，**理论创新性中等偏上，实验充分性偏弱**，更适合作为后续实物实现与鲁棒性拓展的理论起点，而非可直接工程落地的成熟方案。
